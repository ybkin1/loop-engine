## 9. 填写示例

> 以"修改密码哈希算法（MD5 → bcrypt）"变更为例：

| 字段 | 示例值 |
|------|--------|
| 变更类型 | 重构（安全升级） |
| 影响范围 | 直接影响登录模块；间接影响注册模块、密码重置模块 |
| 回归范围 | 选择性回归（登录 + 注册 + 密码重置 + 所有认证相关接口） |
| 核心流程 | TC-AUTH-001(登录), TC-AUTH-002(注册), TC-AUTH-005(密码重置) |
| 变更影响 | TC-AUTH-001(登录-正确密码), TC-AUTH-001B(登录-错误密码), TC-AUTH-001C(旧哈希兼容) |
| 关联模块 | TC-SESS-001(会话管理), TC-PROF-003(个人设置-修改密码) |
| 性能回归 | 登录接口P95: 180ms → 195ms (+8.3%, 在10%阈值内 ✅) |
| 通过标准 | 核心流程 3/3 ✅, 变更影响 3/3 ✅, 关联模块 2/2 ✅, 性能 ✅ |
