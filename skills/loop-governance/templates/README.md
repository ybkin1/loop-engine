# Templates

已完成的治理模板：

- **task-card.md** —— 任务卡模板。用于 `.ai/tasks/T-XXXX.md`，包含基本信息、用户可见目标、范围边界、验收标准、禁止动作、关联 Gate、证据要求、时间记录、版本历史。

- **gate-request.md** —— Gate 请求模板。面向用户的决策展示格式，包含 Gate 基本信息、决策事项说明、背景信息、可选方案、AI 建议、后果分析、决策记录。

- **human-review-packet.md** —— Human Review Packet 模板。阶段结束时由主控生成的面向用户交付物摘要。固定章节结构：阶段概览、参与角色及产出、质量门结果、发现的问题、用户需要做的决策、下一步。

- **phase-delivery-index.md** —— 阶段交付索引模板。面向治理系统内部和下游角色，提供完整的证据定位。包含任务清单、Gate 清单、按类别组织的证据目录、质量门结果、未闭合问题。
