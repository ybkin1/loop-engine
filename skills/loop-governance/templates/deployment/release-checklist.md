## 12. 发布取消/暂停条件

出现以下任一情况，暂停或取消发布：

- [ ] P0 级缺陷在 staging 发现
- [ ] 性能退化 > 20%
- [ ] 安全漏洞在 staging 发现
- [ ] 关键签核人未批准
- [ ] 依赖服务/第三方 API 不可用
- [ ] 部署方案/回滚方案未通过评审
