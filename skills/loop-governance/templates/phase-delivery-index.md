# 阶段交付索引模板

> 使用说明：每个阶段结束时，由交付经理（delivery-manager）生成此索引。
> 此索引是对 Human Review Packet 的补充——Human Review Packet 面向用户，
> 本索引面向治理系统内部和下游角色，提供完整的证据定位。
>
> 存放路径：`.ai/evidence/phase-XX/delivery-index.md`

---

## 阶段概览

| 字段 | 内容 |
|---|---|
| **阶段编号** | Phase XX |
| **阶段名称** | （如：需求整理 / 架构设计 / 功能开发 / 质量验收 / 交付上线） |
| **开始时间** | YYYY-MM-DD |
| **结束时间** | YYYY-MM-DD |
| **负责角色** | （本阶段主负责角色） |
| **阶段状态** | 进行中 / 已完成 / 已验收 |
