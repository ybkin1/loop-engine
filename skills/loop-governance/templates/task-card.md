# 任务卡模板

> 使用说明：创建新任务时，复制此模板填充对应字段。
> 存储在 `.ai/tasks/T-XXXX.md`，其中 XXXX 为四位数字编号（如 T-0001）。
> `task_graph.yaml` 中的条目必须与本文件一致（validate_state.py 会校验）。

---

## 基本信息

| 字段 | 内容 |
|---|---|
| **任务编号** | T-XXXX |
| **任务名称** | （简短描述，如：用户登录功能开发） |
| **所属阶段** | （如：需求整理 / 架构设计 / 功能开发 / 质量验收 / 交付上线） |
| **负责角色** | （如：开发者 / 产品经理 / 质量工程师） |
| **依赖任务** | （前置任务的编号列表，无依赖则填"无"） |
| **当前状态** | pending / active / in_progress / completed / blocked / rejected |

---

## 用户可见目标

> 用非技术语言描述：用户最终能看到什么、能做什么。

（一句话描述，如："用户可以用邮箱和密码注册账号并登录系统"）

> 每一条必须是**可验证的**、**用户可感知的**。

|---|---|---|

| AC-2 | ... | ... |

## 证据要求

| 证据类型 | 路径 | 说明 |
|---|---|---|
| 执行命令记录 | `.ai/evidence/T-XXXX/commands.md` | 记录所有执行的命令和工具调用 |
| 产出物 | `.ai/evidence/T-XXXX/` | 本任务的产出文件 |
| 评审报告 | `.ai/evidence/T-XXXX/review-report.md` | 独立评审报告（如适用） |
