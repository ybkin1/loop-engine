# 非功能需求模板

> **必填表单。** 缺任何必填项 = 打回重做。产品经理/系统架构师角色必须完整填写。
> 参考标准：**IEEE 830 SRS**（Non-Functional Attributes 章节）、**12-Factor App**、**Microsoft Well-Architected**。

## 1. 性能需求（必填，无要求填写"无特殊要求"）

### 1.1 响应时间
| 操作类型 | 目标(P95) | 可接受(P99) | 测量方式 |
|---------|----------|-----------|---------|
| 页面加载 | [如：< 1s] | [如：< 3s] | [Lighthouse / WebPageTest] |
| API 响应 | [如：< 200ms] | [如：< 500ms] | [k6 / JMeter] |
| 数据库查询 | [如：< 50ms] | [如：< 200ms] | [APM工具] |
| 文件上传 | [如：< 5s/MB] | [如：< 10s/MB] | [手动测试] |

**填写示例：**
| 操作类型 | 目标(P95) | 可接受(P99) | 测量方式 |
|---------|----------|-----------|---------|
| 页面加载 | < 1s | < 3s | Lighthouse |
| API 响应 | < 200ms | < 500ms | k6 压测 |
| 数据库查询 | < 50ms | < 200ms | Datadog APM |

### 1.2 吞吐量
| 指标 | 目标值 | 峰值 | 测量方式 |
|------|--------|------|---------|
| 并发用户数 | [如：500] | [如：2000] | [k6 / Locust] |
| QPS (每秒请求数) | [如：1000] | [如：5000] | [k6 / wrk] |
| 数据处理量 | [如：1GB/天] | [如：5GB/天] | [日志/监控] |

## 2. 可用性需求（必填）

| 指标 | 目标 | 说明 |
|------|------|------|
| 系统可用率(SLA) | [如：99.9%] | [全年允许宕机时间] |
| 计划内停机窗口 | [如：每周日 02:00-04:00] | [维护时段] |
| 故障恢复时间(RTO) | [如：< 15分钟] | [从故障到恢复] |
| 数据恢复点(RPO) | [如：< 5分钟] | [最大数据丢失量] |

## 3. 安全需求（必填）

| 需求项 | 是否适用 | 详细要求 | 参考标准 |
|--------|---------|---------|---------|
| 用户认证 | [是/否] | [如：JWT + OAuth2.0] | OWASP ASVS V2 |
| 访问控制 | [是/否] | [如：RBAC 三级权限] | OWASP ASVS V4 |
| 数据加密(传输) | [是/否] | [如：TLS 1.3] | OWASP ASVS V9 |
| 数据加密(存储) | [是/否] | [如：AES-256] | OWASP ASVS V9 |
| 输入校验 | [是/否] | [所有输入服务端二次校验] | OWASP ASVS V5 |
| 日志审计 | [是/否] | [关键操作有审计日志] | OWASP ASVS V7 |
| 防暴力破解 | [是/否] | [如：5次失败锁15分钟] | OWASP ASVS V2 |
| 会话管理 | [是/否] | [如：30分钟无操作过期] | OWASP ASVS V3 |

| 维度 | 要求 |

## 9. 示例：一个Web应用的完整非功能需求

| 指标 | 示例值 |
|------|--------|
| 页面加载(P95) | < 1s |
| API响应(P95) | < 200ms |
| 并发用户 | 500（峰值2000） |
| 可用率 | 99.9%（月宕机<43分钟） |
| 认证方式 | JWT (Access 15min + Refresh 7d) |
| 加密 | TLS 1.3, AES-256 at rest |
| 浏览器 | Chrome/Firefox/Safari 最新版 |
| 部署 | Docker + K8s, 环境变量配置 |
| 日志 | stdout, JSON格式, ELK采集 |
