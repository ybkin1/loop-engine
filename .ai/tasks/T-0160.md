# T-0160: Pi agent Loop 工程升级（对齐 ZCode 治理核心机制）

## 任务概述

基于 ZCode loop-engine v3.12.67 的最新实现与设计文档，升级 Pi agent 已有的
loop 工程（pi-agent-extensions 的 mini-loop 扩展 + 运行时状态面），对齐
ZCode 治理核心机制：
1. gate 生命周期（gates.json 单一事实源：pending→approved/rejected +
   allowed_paths / forbidden_actions / exit_criteria）
2. 状态校验闸（/validate + validate_state 工具：校验链 + fail-closed）
3. 证据 SHA256 锚定（评审记录哈希 + 语义哈希 + 篡改检测）
4. 事件溯源（events.jsonl：10 事件类型 + state_sha256 锚定 + replay-check）
5. HANDOFF 投影（handoff.md + JSON 块契约 + before_agent_start 注入）
6. 反幻觉闸门补漏（FAIL + 0 工具调用同样强制留痕）
7. 升级协议（评审 3 轮上限 → escalation 事件升级用户）
8. 旧数据自动迁移（备份 + 补字段 + fail-open）

不做（二期候选）：阶段机 S0~S11、12 角色契约、委托链 C-00X、心跳/租约。
