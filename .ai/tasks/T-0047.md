## 目标

修复深度审计（2026-07-24）发现的三项实质性风险：

### 修复 1：Core 层 fail-open → fail-closed
- `enforcement_hub.py` 的 `_read_state()`, `_read_gates()`, `_read_tasks()` 在文件损坏/缺失时静默返回空默认值
- 导致 C1/C2/C5/C6/C7 约束全部跳过，整个治理系统架空
- **改为**：损坏/缺失时返回错误哨兵值，上层检测到哨兵后拒绝写入

### 修复 2：role_isolation.py 补测试 + fail-closed
- 当前零测试覆盖，且 state 读取异常 → 静默放行（fail-open）
- **改为**：state 读取异常 → 阻断（exit 2），与 HARD enforcement 声明一致
- 新增 `tests/test_role_isolation.py` 覆盖正常路径 + 异常路径

### 修复 3：补全 corruption/负面路径测试
- 全库仅 2 个 corruption 测试
- 新增：gates.yaml 损坏、task_graph.yaml 损坏、证据目录不可读、
  enforcement_hub 在损坏 state 下的决策、端到端证据 hash 篡改检测

## 验收标准

1. `_read_state()` 损坏/缺失时返回哨兵值，`should_allow_write()` 拒绝写入
2. `_read_gates()` 损坏/缺失时返回哨兵值，`quick_check()` 拒绝
3. `role_isolation.py` 异常时 exit 2（不是 exit 0）
4. 新增 ≥20 个 corruption/负面路径测试
5. 全量回归无新增失败
