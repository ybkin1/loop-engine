# T-0144: repro_norm 规范化规则实现（legacy 4.3）

## 任务概述

实现 D-02 M1 承诺的复算输出规范化（repro_norm）——复算执行器当前用
原始 stdout+stderr 哈希约定，含耗时/绝对路径/时间戳导致同一报告复算
哈希不稳定。落地：`loop_core/guard_health.py` 复算执行器消费 repro_norm
字段（strip-timestamps / strip-absolute-paths），与报告生产方约定一致。

## 业务范围

- 设计来源：T-0133 审查遗留 4.3 / T-0132 D-02 M1
- 落地：guard_health.py `run_sampled_recompute` 支持报告可选
  `repro_norm` 字段（如 `["strip-timestamps", "strip-absolute-paths"]`），
  规范化后再哈希；未规范化字段时保持原行为（向后兼容）
- 规范化规则：strip-timestamps（ISO8601/epoch 时间戳 → 占位符）、
  strip-absolute-paths（绝对路径 → 相对路径占位）
- 文档：recompute-events 说明 repro_norm 语义
