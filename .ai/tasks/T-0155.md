# T-0155: 事件溯源影子层（loopx 借鉴 P0-1）

## 任务概述

loopx 对比结论 P0-1：为 Loop 工程引入事件溯源影子层 —— 对治理状态
写入追加 JSONL 事件日志（todo/gate/evidence 生命周期），state.yaml 仍为
权威投影，事件链提供审计可追溯性（谁在何时改了什么状态可回放）。
**影子层只读审计流，不改变任何现有判定语义。**

## 业务范围

- 设计来源：docs/designs/T-0154-loopx-comparison.md P0-1
- 落地：`.zcode/tools/event_log.py` —— 追加写
  `.ai/evidence/observability/state-events.jsonl`，事件类型：
  `task_registered/task_status_changed/gate_created/gate_approved/
  gate_completed/evidence_attached/handoff_generated`
- 事件字段：`{ts, event_id, event_type, actor, task_id, gate_id, detail, state_sha256}`
- 接入点：validate_state --auto-sync 时记录投影变化（最小侵入）；
  提供 `read_events` 回放 API + `replay_check`（投影=事件回放一致性）
- **失败吞掉**（观测绝不阻断业务，沿用 guard-events 原则）
