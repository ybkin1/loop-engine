# T-0156: 配额决策路由（loopx 借鉴 P0-2）

## 任务概述

loopx 对比结论 P0-2：在 cost_tracker 之上引入配额决策路由 —— 输入
成本账本 + gate 状态 + 悬空轮次，输出 5 态决策
（deliver/ask/wait/repair/quiet）+ reason。**只建议不执行**（/loop-quota
命令），与用户 gate 驱动哲学兼容；默认 quiet/wait（fail-safe）。

## 业务范围

- 设计来源：docs/designs/T-0154-loopx-comparison.md P0-2
- 落地：`loop_engine/quota_decision.py` —— `decide_quota(ctx)` 返回
  `{decision: deliver|ask|wait|repair|quiet, reason, factors}`
- 决策输入：cost_tracker.summary()（token 成本/返工率）、pending gates、
  rounds_heartbeat 悬空、上次决策时间
- 决策规则（fail-safe）：
  - 有 pending gate → ask（需要用户）
  - 悬空轮次 > 0 → repair（需修复）
  - 成本超预算阈值 → quiet（暂停）
  - 成本正常 + 无阻塞 → deliver（可继续）
  - 不确定 → wait（默认保守）
- CLI：`/loop-quota`（loop_engine/cli_entries.py 或独立入口），
  **只输出建议不自动执行**
- 5 态决策单测矩阵
