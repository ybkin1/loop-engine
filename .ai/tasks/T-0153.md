# T-0153: 手机 PWA 叠加层原型（T-0001 延续方向）

## 任务概述

用户方向（T-0001 延续）：为 NordRelay 会话体系构建独立于桌面 WebUI 的
移动端 PWA 叠加层（ZCode 截图风格）。本任务为 **candidate 原型**（仓库内
实现，不触碰外部系统/公网）：
- 工作区首页（按 /api/sessions 分组）
- 会话列表/详情
- 实时事件（NordRelay SSE 流消费）
- 发消息、abort、切模型
- 设备配对流程设计（二维码 → 一次性登录码 → 持久 token 的映射设计）

> **边界声明**：NordRelay 为外部系统（本仓库零引用）。本任务仅做
> **原型与适配层设计**（mock/接口契约），真实对接 NordRelay 实例、
> 公网反代（Caddy/Cloudflare Tunnel）、WSS relay 属外部边界，
> 必须用户单独 gate 后方可执行。

## 业务范围

- **PWA 骨架**：manifest.json + service worker + 移动端页面壳（HTML/CSS/JS
  原生或轻量，ZCode 截图风格深色 UI）
- **API 客户端契约**：/api/sessions 分组、会话详情、发消息、abort、
  切模型 —— 以 mock server 形式实现（不连真实 NordRelay）
- **SSE 消费**：EventSource 封装 + 事件渲染（实时事件流）
- **设备配对设计**：二维码 → 一次性登录码 → 持久 token 的映射方案文档
  （含 token 存储安全考量；不实现真实配对服务）
- 交付：原型可本地运行（mock 模式）+ 设计文档
