# T-0099: Loop 工程自身质量验收 — 全能力端到端验收

## 任务概述

把 loop-engine 项目自身作为"已完成开发、待验收"的交付项目，用本工程已建成的全部治理能力做**端到端质量验收**（dogfooding）：静态门禁 + 动态质量 + 治理质量 + 发布就绪评估 + 统一验收报告 + 独立审查。

## 用户目标

1. 静态门禁：validate_state + compile_gate + 版本一致性 + capability registry（missing/drift）+ guard 健康
2. 动态质量：全量测试回归 + eval 栈内置样例 + 契约平面 conformance
3. 治理质量：SLO/error budget + 学习回路（incident/second-failure）+ 安全扫描 + 自举审计
4. 发布就绪：release.py check（6 步质量门）
5. 产出：统一质量验收报告（每项 PASS/FAIL/证据/裁决）+ dashboard 快照 + 独立审查验证

## 业务范围

- **IN SCOPE**:
  - 静态门禁组：`validate_state.py`（[ok] usable）+ `compile_gate.py`（编译全过）+ `test_version_consistency`（版本一致）+ `tool_registry_status`（注册表 missing/drift 0）+ `loop_guard_health`（guard 5/5 ALIVE）
  - 动态质量组：全量 `pytest tests/`（0 failed）+ `tool_eval.py`（内置 guard 样例全过）+ `vertical_slice` conformance（gate PASS）
  - 治理质量组：`loop_metrics`（SLO/error budget 状态）+ `second_failure_checker`（无未解决）+ `security scan`（无阻断级）+ `loop_self_audit`（规则式全过，--llm 可选尝试）
  - 发布就绪组：`release.py check`（6 步质量门）
  - 统一质量验收报告：.ai/evidence/T-0099/acceptance/quality-acceptance-report.md（每项：标准/结果/证据/备注）+ 裁决（GO/CONDITIONAL_GO/NO-GO）+ dashboard 快照更新
  - independent-reviewer 对验收执行与报告做独立验证

- **OUT OF SCOPE**:
  - 修复验收发现的问题（仅记录为 findings，修复需用户另行发起）
  - 真实发布执行
  - 部署、回滚、数据库迁移、生产权限修改、生产数据处理
  - **不得弱化任何已激活约束**
