# T-0112: Qoder 会话源恢复与可比较观察窗口

## 任务概述

修复 Better Harness 报告中的 `session-source-disabled` 机制缺陷：Qoder 工作区会话证据源出现 `disabled-source-root` / `missing-optional-root`，仅 1/5 个 enabled source roots 存在，导致即使存在会话也无法读取，任务理解、可控执行、改动验证、可靠交付持续处于 Unobserved，学习捕获无法形成可比较窗口。

本任务独立于 T-0107 的代码正确性修复；不通过伪造 Episode、放宽评分上限或修改 Loop 安全裁决来提升分数。

## 执行批次

1. **治理与配置基线**：确认 Qoder/Better Harness 工作区配置入口、adapter 版本、导入边界和脱敏要求。
2. **Source-root 健康检查**：逐一诊断 5 个 enabled root 的 configured/resolved/exists/readable/sessionCount/eligibleCount/reason。
3. **会话源恢复**：在独立批准范围内启用或修复 Qoder 会话证据源、路径解析和读取权限；不修改 Loop 治理内核。
4. **事实重新收集**：重新运行会话事实收集，确认 eligible sessions 和 source gap 状态。
5. **Episode 验证**：导入至少两个真实、可比较、已脱敏的 Task Episode，覆盖 session start、task identification、edit、validation、close，以及一次 rework/recovery。
6. **重新评审**：带非空 evidenceRefs 重新评估任务理解、可控执行、改动验证、可靠交付和经验沉淀。
7. **独立审查与收口**：审查 source 配置修复真实性、证据可追溯性、隐私边界和评分不得被人为抬高。

## 可验证验收标准

- [ ] 五个 source root 均有逐项诊断状态；不可用 root 有明确错误码和修复建议。
- [ ] `eligibleSessions > 0`，且无未解释的 `disabled-source-root`；`sourceGaps` 为空或逐项有明确可接受原因。
- [ ] 至少两个可比较 Task Episode 成功导入。
- [ ] Episode 至少覆盖一次 edit→validation 和一次 rework/recovery。
- [ ] Episode 与 task/session/gate 可关联，evidenceRefs 非空、可追溯、已脱敏。
- [ ] 重新评审后，四个受影响维度不再因会话源缺失被锁定；经验沉淀具备可比较窗口。
- [ ] 未满足上述条件时，报告保持 `NO_EVIDENCE` / `INSUFFICIENT_SAMPLE`，不输出确定性行为结论。
