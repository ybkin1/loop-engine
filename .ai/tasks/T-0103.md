# T-0103: 提示词工程全量盘点 + 四象限整合设计（candidate-only）

## 任务概述

基于用户提供的"人机协作四象限"方法论（Q1 已知的已知→直接执行 / Q2 已知的未知→老师问答 / Q3 未知的未知→盲点自检 / Q4 未知的已知→原型逼近，外加执行前/中/后三阶段操作法），全量盘点 loop 工程提示词工程资产，做四象限差距分析，产出整合设计候选（candidate-only，不落地任何生产代码），并以 B1 eval 最小实验设计为后续验证铺路。

## 用户目标

1. 全量盘点 loop 工程提示词工程资产（角色 SKILL / 技能模板 / hook 注入 / 上下文与记忆 / LLM 层 / eval 栈 / 用户级 AGENTS.md）
2. 四象限（Q1-Q4）+ 执行前/中/后三阶段差距分析（已有/差距/增强点）
3. 整合设计候选：盲点自检模板（Q3 前置）、任务卡 Q1-Q4 定位声明区、执行中偏离日志、执行后反向考察
4. B1 eval 最小实验设计（有/无盲点自检提示词的单一变量对照）
5. independent-reviewer 独立审查 + 用户决策包（全部 candidate-only）
