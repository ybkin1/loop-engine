# T-0030: 抽离 Loop Core 协议

## Status

`completed`


## 目标

将 Loop 工程控制内核从 ZCode 插件代码中独立出来，形成宿主无关的协议层。

## 架构

```
loop_core/                    ← 宿主无关（新增）
├── README.md                 ← 协议说明
├── schemas/                  ← JSON Schema 数据契约
│   ├── state.schema.json
│   ├── gate.schema.json
│   ├── task.schema.json
│   ├── role_contract.schema.json
│   ├── evidence.schema.json
│   └── phase.schema.json
├── state_machine.py          ← 宿主无关状态机
├── enforcement.py            ← ENFORCEMENT_LEVEL 定义 + 校验
└── router.py                 ← 项目分级 + Loop 路由

loop-engine/                  ← 现有代码（成为 ZCode Host Adapter）
├── .zcode-plugin/            ← ZCode 适配器入口
├── hooks/                    ← ZCode 强集成能力
├── tools/                    ← MCP 工具（可复用）
├── agents/                   ← 角色合同（可复用）
└── ...
```

## 子任务

1. 创建 `loop_core/schemas/` — 6 个 JSON Schema
2. 实现 `loop_core/state_machine.py` — 阶段转换、Gate 状态机
3. 实现 `loop_core/router.py` — 项目分级判断 + Loop 路由
4. 实现 `loop_core/enforcement.py` — ENFORCEMENT_LEVEL 分级
5. 定义 Host Adapter 接口契约
