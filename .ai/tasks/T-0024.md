# T-0024: Loop Engine 接口契约设计

## 目标

编写 `docs/03-interface-contract.md`，精确定义 Loop Engine 四层架构中各模块间的接口契约，包括 Hook JSON schema、MCP 工具 inputSchema、Skill 协议和命令参数格式。

## 范围

- **输入**：`docs/02-architecture.md`（架构设计）
- **交付物**：`docs/03-interface-contract.md`
- **类型**：design-only

## 子任务

1. Hook 层接口契约：SessionStart / PreToolUse 的 stdin JSON、stdout JSON schema
2. MCP 工具层接口契约：7 个工具的 inputSchema / output schema
3. Skill 层协议：SKILL.md 的 when_to_use / 启动检查清单 / 输出格式约定
4. 命令层接口：3 个斜杠命令的参数和输出格式
5. 治理数据 schema：state.yaml、gates.yaml、task_graph.yaml 的字段定义

## 验收

- `docs/03-interface-contract.md` 存在且覆盖全部 5 个子任务
- 每个接口有明确的 JSON Schema 或字段定义表
- 与架构设计文档可追溯

## 生命周期

- 阶段: S2-architecture → S3-interface
