## 用户目标

1. 知识存储：结构化记录（决策/经验/教训）+ 多维度检索（任务/gate/主题/关键词）
2. 记忆服务：跨任务经验提取（从 gate 决策/gate_lessons/验收记录）与注入（决策包/路由上下文）
3. 与 T-0089 gate_feedback 整合（统一经验来源，不重复造轮子）
4. 与 U3 context_loader 衔接（记忆可选注入上下文）
5. 全量测试无回归

## 业务范围

- **IN SCOPE**:
  - `loop_core/knowledge_store.py`（或等效）：KnowledgeEntry schema（entry_id/类型（decision/lesson/pitfall/best_practice）/来源（task_id/gate_id）/主题标签/内容/时间戳/版本）+ 写入（幂等去重）+ 检索（by_task/by_gate/by_tag/keyword）+ 落盘（.ai/evidence/knowledge/knowledge-store.yaml 或 JSONL）
  - `loop_core/memory_service.py`（或等效）：跨任务经验提取（从 gate_lessons/验收报告/commands 提取结构化经验 → knowledge store）+ 注入（按任务/主题检索相关经验 → human_review_packet 相关经验段 / context_loader 记忆段）
  - 与 gate_feedback 整合：record_gate_lesson 时同步提取知识（或 knowledge_store 读取 lessons 作为来源）
  - context_loader 可选记忆注入（新参数，默认关闭，不影响现有行为）
  - 配套测试 + 全量回归

- **OUT OF SCOPE**:
  - 文档解析/OKF 知识库（StaffDeck 重功能，治理域不需要）
  - LLM 提取（可选后续；本任务规则式提取）
  - 部署、回滚、数据库迁移、生产权限修改、生产数据处理
  - **不得弱化任何已激活约束**
