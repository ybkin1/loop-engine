# F-01（P2）tool_registry_status --json 崩溃 — AC-02

## 根因

`tools/tool_registry_status.py` 中局部变量 `death` 只在文本分支（`else`）内
赋值（`death = integrity["death"]`），`--json` 模式不经过该分支；第 82 行
`if death["overall"] != "PASS"` 在 `--json` 模式下触发 **UnboundLocalError**
—— 打印完合法 JSON 后必崩，健康状态也退出码 1（T-0099 G1-4 实测）。

## 改动

`tools/tool_registry_status.py`：把 `death = integrity["death"]` 提取到
`if args.json / else` 分支**之前**统一取用（两个模式共用同一份判定），
并加注释说明 F-01 修复。退出码语义不变：0 = 健康；1 = missing/drift 报告级；
2 = guard BROKEN/DORMANT（death fail-closed）。
