# F-05（P2）SLO 口径/语义 — AC-04

## 根因

1. **release_fee 口径不一致**：T-0099 验收实测 metrics 报告 consumed 0.0
   （`tools/loop_metrics.py` 默认 `--releases 0`，不评估 release fee）vs
   release.py check 的 slo_gate consumed 5.0（`check_slo_gate(releases=1)`）。
   同一预算模型被两个调用点以不同默认值使用，且无一致性保障。
2. **整体 NOT_VERIFIED 语义过粗**：`build_report` 只要有源缺失或任一 SLI
   NOT_AVAILABLE 即整体 NOT_VERIFIED；wave-2 ledger 数据源（
   phase_transitions/guard_decisions/runtime-events 等 14 项）是文档化
   未接线项（B2 §2.2），因它们未接线而把整个 error budget 判为不可信，
   掩盖了已接线 computed 项的真实值。

## 改动

### `loop_core/governance_metrics.py`

1. **release_fee 单一函数**：新增 `release_fee_consumption(release_fee_units,
   releases)`（`releases * release_fee_units`，0 次发布不计费）；
   `compute_error_budget` 改为调用它（唯一实现）。
2. **未接线源分类**：`WAVE2_UNWIRED_SOURCES = {phase_transitions.jsonl,
   guard_decisions.jsonl, runtime-events.jsonl}`；`UNWIRED_SLI_IDS` 含 6 个
   依赖未接线源/尚未落盘的 SLI。
3. **逐项 advisory 标注**：
   - `evaluate_sli` 结果新增 `advisory` 字段 —— 未接线源缺失分支
     （guard_block_rate / drift_event_rate 的"源缺失"分支）与"尚未记录"分支
     （delta_quality_pass_rate / evidence_regeneration_rate /
     defect_fail_verdict_rate / ac_invest_rate）置 True；源已存在但无数据的
     分支保持非 advisory（真实数据情形，fail-closed 不变）；
   - DORA 指标中依赖未接线源的 5 项（phase_dwell_time /
     rework_cycles_from_transitions / guard_block_pass_error_rates /
     drift_events / evidence_regeneration_events）`_not_available(..., advisory=True)`；
   - `build_report`：未接线源缺失 → `advisories`（逐项注明"wave-2 项，不影响
     computed 判定"），不进 `missing`；**status 仅由已接线源问题驱动**（已接线
     源缺失/不可解析或非 advisory 的 NOT_AVAILABLE → NOT_VERIFIED，fail-closed
     保持）；advisory 存在时 notes 汇总"部分源未接线，computed 项正常判定"。
   - `MetricsReport` 新增 `advisories` 字段并进入 `to_dict`/`render_markdown`
     （新增 Advisories 小节）。
4. 模块 docstring 更新为"已接线源 NOT_VERIFIED / 未接线源 advisory"策略。

### `loop_core/slo_gate.py`

- **门禁语义零改动**（REQUIRED_SOURCES fail-closed、未接线源为 gate 非输入、
  exemption/恢复机制均不变）；模块 docstring 明确 release_fee 经
  `governance_metrics.release_fee_consumption`（经 `compute_error_budget`
  引用）单一实现，与 metrics 口径一致。

### `tools/loop_metrics.py`

- `--releases` help 增加口径提示（release.py check 按 releases=1 评估本次
  发布，metrics 传同一值即与 slo_gate 一致）；stdout 打印 advisories 清单。
