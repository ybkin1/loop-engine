# F-04（P2）pip-audit 环境不可用误报 — AC-03

## 根因

`agents/security-engineer/scripts/run_security_scan.py::_run_pip_audit`：
pip-audit 因本机 Python 3.12 安装缺 stdlib `venv` 直接崩溃（
`ModuleNotFoundError: No module named 'venv'`，exit=1），脚本把"任何非零
退出码"一律 `counts["HIGH"] = max(1, ...)` → **合成 HIGH:1 → BLOCKED**。
环境故障被当成漏洞证据（fail-closed 误用：环境不可用 ≠ 存在 CVE）。

## 改动

`agents/security-engineer/scripts/run_security_scan.py`（`_run_pip_audit` /
`_run_npm_audit` / `run_dependency_scan` / `generate_report`）：

- 返回三元组 `(counts, raw, skip_reason)`：
  - **真实结果**（stdout 可解析为漏洞 JSON；pip-audit exit=1 检出漏洞属正常
    输出形态）→ `skip_reason=None`，HIGH/CRITICAL 照常 blocked（阻断语义不变）；
  - **环境不可用**（命令缺失 FileNotFoundError / 超时 / 执行异常 / 输出不可解析
    且非零退出）→ `skip_reason=明确原因`（含工具名 + exit 码 + stderr 尾行），
    counts 保持全零，**绝不合成 HIGH**；
  - 零退出无输出 → 视为无漏洞（pass）。
- `run_dependency_scan`：环境不可用 → `status="skipped"` + `reason` +
  `skipped: True`（字段 `dependency_check=SKIPPED` 语义）；真实结果 →
  `pass/blocked` 原逻辑。
- `generate_report`：`skipped` 不进入 `blocked_by`（不阻断整体），Markdown
  显示 `⏭️ SKIPPED — <原因>`；overall BLOCKED 仅由真实 blocked 项驱动。
- 模块 docstring 补充 SKIPPED 语义说明。

AC-07 保持：SKIP 必附原因；真实 CVE 扫描结果（含退出码 1 的漏洞 JSON）仍按
原逻辑判定（HIGH/CRITICAL → blocked）。
