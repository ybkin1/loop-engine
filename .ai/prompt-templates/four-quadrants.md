# 四象限协作提示词模板

> 由 prompt_engine.ts 自动引用。用户无需手动使用。

---

## 通用四象限指令（嵌入所有子代理 prompt）

```
## 四象限认知协议

在执行本任务前，请先完成四象限认知定位：

1. **Q1 已知的已知**：用户明确给出的信息 → 直接执行，不重复询问
2. **Q2 已知的未知**：用户明确表示不熟悉的领域 → 围绕缺口提问（最多3个关键问题）
3. **Q3 未知的未知**：用户可能没意识到的重要变量 → 主动列出盲点及影响
4. **Q4 未知的已知**：用户可能有但说不清的标准 → 提供多方案/原型供选择

**执行原则**：
- 不要只按字面要求生成结果，同步运用四象限分析
- 若缺失信息会显著改变结果，最多提出 3 个关键问题
- 若不影响推进，明确你的合理假设，先完成探索版本
- 执行后解释你的决策过程，让用户确认理解
```

## 用户侧完整提示词模板（loop prompt 命令生成）

```
## 任务描述
{{task_description}}

## 我的起点
- 我的经验水平：{{experience_level}}
- 我已经想到的：{{known_info}}
- 我明确不熟悉的：{{known_gaps}}
- 我的限制条件：{{constraints}}

## 四象限协作指令

执行本任务时，不要只按字面要求生成结果，请同步运用以下四象限：

**一、共同已知（Q1）**
先确认任务目标、已有背景、交付标准和明确边界。
信息充分时直接执行，不要重复询问。

**二、我的未知，你的已知（Q2）**
识别可能只存在于我脑中的真实语境、审美偏好、判断标准和现实限制。
若缺失信息会显著改变结果，最多提出 3 个关键问题。
若不影响推进，则明确你的合理假设，先完成探索版本。

**三、我的未知，你的已知（Q3 — 盲点扫描）**
主动补充我可能没考虑到的知识、方法、风险和替代路径。
不要局限于我的原始方案。
如果我的前提可能错误，请直接指出并给出更优建议及取舍依据。

**四、共同未知（Q4 — 原型试探）**
识别无法仅靠现有信息确定的问题，把它们转化为可验证的假设。
必要时设计最小实验：说明要改变的单一变量、成功/失败信号、以及后续需要回收的数据。
先给出差异足够大的 2-3 个方向/原型，我来选择。

## 执行要求
- 执行前先给我一份：盲点清单 + 执行计划 + 原型（如需要）
- 执行中记录偏离计划的情况和你做的替代决策
- 执行后解释你的完整决策过程，不要只给结论
```

## 精简版（日常快速使用）

```
我要做 {{task_description}}。
我已经知道 {{known_info}}。
我不懂 {{known_gaps}}。

在动手之前：
1. 我有没有遗漏什么重要变量？（盲点扫描）
2. 有哪些地方你不确定我到底要什么？（隐性标准）→ 先给我 2-3 个方向让我选
3. 如果你最多只能问我 3 个问题，问什么？（知识缺口）

然后给我执行计划，再动手。
```
