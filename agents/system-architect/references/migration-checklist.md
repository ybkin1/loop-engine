# 数据迁移设计检查清单（system-architect）

> **T-0136 D-03 落地。** 架构师在迁移方案设计时使用。
> 配套模板：`skills/loop-governance/templates/migration/data-migration-plan.md`

## 必查项

- [ ] 迁移方案三件套齐备：双写方案 + 回滚方案 + 校验方案
- [ ] 百亿表场景强制：分批搬迁 + 断点续传 + 追平水位监控
- [ ] 灰度切流档位表（≥3 档 + 每档验证指标）
- [ ] 回滚触发条件预定义（量化阈值）
- [ ] 数据校验方案（计数 + 抽样哈希 + 对账）
- [ ] 单体拆分场景：数据边界先行 + 兼容层 + 影子流量对比

## 边界提醒

- 本清单是**设计方法论**；实际迁移执行属外部边界（forbidden migration），
  必须用户单独 gate 批准
