# 一致性设计检查清单（system-architect）

> **T-0136 D-05 落地。** 架构师在架构评审时使用。
> 配套模板：`skills/loop-governance/templates/consistency/consistency-design.md`

## 必查项

- [ ] 每个数据流标注一致性等级（强/最终）+ 依据
- [ ] 缓存失效方案（更新后删缓存）+ 补偿机制（延迟双删/消息重试）
- [ ] 消息链路不丢设计（confirm + 持久化 + 手动 ack + DLQ）
- [ ] 幂等设计（生产端唯一 ID + 消费端唯一键）
- [ ] 对账/补偿任务存在（业务表 vs 消息状态）

## 边界提醒

- 分布式事务（2PC/XA/事务消息）不在本模板展开（T-0136 D-05 裁剪）；
  以幂等 + 补偿达成最终一致为主轴
