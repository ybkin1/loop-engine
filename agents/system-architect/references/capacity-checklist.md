# 容量设计检查清单（system-architect）

> **T-0136 D-01 落地。** 架构师在 S1/S2 阶段与 NFR 评审时使用。
> 配套模板：`skills/loop-governance/templates/capacity/capacity-estimate.md`

## 必查项

- [ ] NFR 容量部分附 capacity-estimate 表单（含假设清单，每项可追溯）
- [ ] 峰值场景已覆盖（运营活动 ≥10× 日常时必须显式建模；面试题基准
      2000→20 万 QPS = 100×）
- [ ] 读/写比例已拆分（决定缓存/异步/分库分表方向）
- [ ] 资源粗算含冗余系数（N+1/N+2）与带宽
- [ ] 选型时必须回答"流量翻一倍/十倍是否成立"（容量可扩展性验证）
- [ ] 单机吞吐基线按复杂度标注（不得用"大家都行"当依据）

## 与压测的闭环

- [ ] 压测实测值回填容量表单（偏离 >30% 需更新估算）
- [ ] 容量上限拐点与资源冗余匹配（撑不到 2× 目标需说明）
