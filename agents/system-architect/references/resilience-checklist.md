# 稳定性设计检查清单（system-architect）

> **T-0136 D-02 落地。** 架构师在架构评审时使用。
> 配套模板：`skills/loop-governance/templates/stability/resilience-design.md`

## 必查项

- [ ] 核心链路熔断/限流/降级三件套齐备
- [ ] 熔断阈值有推导文档（SLO 反推或基线实测，非抄默认值）
- [ ] 降级方案明确"降级后用户体验"（业务无感知 / 降级感知）
- [ ] 超时配置 ≤ 下游 p99 的 50%
- [ ] 半开恢复策略明确（窗口 + 试探比例 + 成功阈值）
- [ ] 恢复判定三层齐备（熔断器 / 业务指标 / 依赖健康）

## 与防御演练的衔接

- [ ] 降级演练记录存在（注入故障 → 验证降级 → 恢复判定）
- [ ] 演练发现偏差已回填设计（阈值/方案修正）
