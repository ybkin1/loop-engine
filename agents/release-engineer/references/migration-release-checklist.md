# 迁移发布检查清单（release-engineer）

> **T-0136 D-03 落地。** 发布工程师在迁移切换期使用。
> 配套模板：`skills/loop-governance/templates/migration/data-migration-plan.md`

## 必查项（缺任一 = NOGO 候选）

- [ ] 迁移方案文档存在（双写/回滚/校验三件套）
- [ ] 回滚触发条件预定义（量化阈值，非"出问题再说"）
- [ ] 灰度切流档位表（≥3 档 + 每档验证指标）
- [ ] 数据校验方案（计数 + 抽样哈希 + 对账）
- [ ] 回滚演练记录（注入异常 → 回滚 → 恢复）
- [ ] 切换后 24h 对账任务已配置

## 常见驳回场景

- 无回滚预案演练 → 驳回（切流前必须演练）
- 一步全量切流无灰度 → 驳回
- 无数据校验方案 → 驳回（"应该没丢"不可接受）
