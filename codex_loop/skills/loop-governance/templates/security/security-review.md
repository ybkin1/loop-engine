## 13. 填写示例

> 以 Web 应用登录模块的安全审查为例：

| 检查项 | 示例结果 |
|--------|---------|
| 密码最小长度 | ✅ 要求 ≥ 8 位 |
| 密码存储 | ✅ 使用 bcrypt (cost=12) |
| 登录失败锁定 | ✅ 5次失败锁定15分钟 |
| 会话令牌 | ✅ HttpOnly + Secure + SameSite=Strict |
| SQL注入防护 | ✅ 使用ORM参数化查询 |
| XSS防护 | ❌ 用户昵称未做HTML编码（SEC-H-001） |
| IDOR防护 | ✅ 每个API校验资源所有权 |
| 文件上传 | ✅ 校验MIME+扩展名，重命名存储 |
| TLS | ✅ TLS 1.3, HSTS max-age=1年 |
| 依赖安全 | ✅ pip-audit 零高危 |
| DEBUG模式 | ✅ 生产环境关闭 |
| 审查结论 | 有条件通过：SEC-H-001 需在下版本修复 |
