# 用户画像模板

> **必填表单。** 缺任何必填项 = 打回重做。产品经理角色必须完整填写。
> 参考标准：**IEEE 830 SRS** 用户特征章节，**Mountain Goat Software User Stories**。

## 1. 画像基本信息（必填）

### 1.1 画像标识
| 字段 | 内容 |
|------|------|
| 画像编号 | UP-001 |
| 画像名称 | [如：初级开发者小张] |
| 创建者 | [角色/姓名] |
| 创建日期 | YYYY-MM-DD |
| 版本 | v1.0 |

### 1.2 人口统计特征（必填）
| 维度 | 描述 |
|------|------|
| 年龄段 | [如：22-30] |
| 职业/角色 | [如：前端开发工程师] |
| 教育背景 | [如：计算机本科] |
| 技术能力 | [无 / 基础 / 中等 / 专业] |
| 行业经验 | [如：1-3年Web开发] |

## 2. 使用行为（必填）

### 2.1 使用场景
| 维度 | 描述 |
|------|------|
| 使用频率 | [每天 / 每周 / 每月 / 偶尔] |
| 使用环境 | [办公室 / 远程 / 移动端 / 桌面端] |
| 主要设备 | [Windows PC / MacBook / iPhone / ...] |
| 网络条件 | [高速 / 一般 / 受限] |
| 使用时段 | [如：工作日 9:00-18:00] |

### 2.2 核心目标（必填，至少 3 个）
| 编号 | 目标（用户想达成什么） | 当前痛感（为什么现在不行） | 期望结果 |
|------|----------------------|--------------------------|---------|
| UG-001 | [如：快速找到项目中的Bug] | [如：日志分散在多个系统] | [如：一个页面汇总所有错误] |
| UG-002 | [目标2] | [痛感2] | [期望2] |
| UG-003 | [目标3] | [痛感3] | [期望3] |

### 2.3 任务清单（必填，至少 5 个典型任务）
| 编号 | 任务描述 | 频率 | 重要性(P0/P1/P2) |
|------|---------|------|-----------------|
| UT-001 | [如：每天查看待修复的Bug列表] | [每天] | P0 |
| UT-002 | [任务2] | [频率] | [优先级] |
| UT-003 | [任务3] | [频率] | [优先级] |
| UT-004 | [任务4] | [频率] | [优先级] |
| UT-005 | [任务5] | [频率] | [优先级] |

## 3. 痛点与需求（必填）

### 3.1 当前痛点（至少 3 个）
| 编号 | 痛点描述 | 影响程度(高/中/低) | 发生频率 |
|------|---------|-------------------|---------|
| PP-001 | [痛点描述] | [高] | [每天] |
| PP-002 | [痛点描述] | [中] | [每周] |
| PP-003 | [痛点描述] | [低] | [偶尔] |

### 3.2 未满足的需求
| 编号 | 需求描述 | 当前替代方案 | 替代方案的不足 |
|------|---------|------------|--------------|
| UN-001 | [需求] | [用户现在怎么凑合] | [凑合方案的问题] |
| UN-002 | [需求] | [替代方案] | [不足] |

## 4. 心理模型（必填）

### 4.1 用户期望
| 维度 | 期望 |
|------|------|
| 学习曲线 | [如：10分钟内上手 / 无需培训] |
| 操作方式 | [如：全键盘操作 / 拖拽为主] |
| 响应速度 | [如：点击后 <200ms 反馈] |
| 容错期望 | [如：误操作可撤销 / 有确认提示] |

|------|---------|------|
| DH-001 | [如：强制注册才能使用] | [用户认为门槛太高] |
