# 测试用例模板

> **必填表单。** 缺任何必填项 = 打回重做。质量工程师/开发者角色必须完整填写。
> 参考标准：**IEEE 829 Test Case Template**、**OWASP Web Security Testing Guide**。

## 1. 用例标识（必填）

| 字段 | 内容 |
|------|------|
| 用例编号 | TC-[模块缩写]-[序号]（如：TC-AUTH-001） |
| 用例名称 | [简短描述测试内容] |
| 所属模块 | [如：用户认证模块] |
| 关联需求 | [如：FR-001] |
| 测试类型 | [单元测试 / 集成测试 / E2E / 性能测试 / 安全测试] |
| 优先级 | [P0 / P1 / P2] |
| 创建者 | [角色/姓名] |
| 创建日期 | YYYY-MM-DD |
| 最后执行日期 | YYYY-MM-DD |
| 最后执行结果 | [通过 / 失败 / 未执行] |

## 2. 测试环境（必填）

| 环境项 | 配置 |
|--------|------|
| 操作系统 | [如：Ubuntu 22.04] |
| 浏览器/客户端 | [如：Chrome 120] |
| 测试框架 | [如：pytest 8.x] |
| 数据库 | [如：PostgreSQL 16] |
| 预置数据 | [如：test@example.com / Pass123!] |
| 环境变量 | [如：DEBUG=false, LOG_LEVEL=INFO] |

## 3. 前置条件（必填）

- [ ] [前置条件1：如：数据库中存在用户 test@example.com]
- [ ] [前置条件2：如：用户处于未登录状态]
- [ ] [前置条件3：如：Redis 缓存已清空]

## 4. 测试步骤（必填）

| 步骤编号 | 操作描述 | 测试数据 | 期望结果 |
|---------|---------|---------|---------|
| Step-1 | [如：打开登录页面] | [URL: /login] | [页面正常加载，显示登录表单] |
| Step-2 | [如：输入邮箱] | [test@example.com] | [输入框显示输入内容] |
| Step-3 | [如：输入密码] | [CorrectPass123!] | [密码以圆点遮蔽显示] |
| Step-4 | [如：点击"登录"按钮] | - | [页面跳转到 /home] |
| Step-5 | [如：验证跳转结果] | - | [URL 变为 /home，显示欢迎信息] |

## 5. 测试数据（必填）

| 数据项 | 值 | 说明 |
|--------|-----|------|
| 邮箱 | test@example.com | 已注册用户 |
| 密码 | CorrectPass123! | 正确密码 |
| 错误邮箱 | wrong@example.com | 未注册用户 |
| 错误密码 | WrongPass456! | 错误密码 |
| 空值 | "" | 空字符串 |
| 超长字符串 | "a" * 1000 | 边界测试 |

## 6. 期望结果（必填）

### 6.1 正常流程期望
- [ ] [如：HTTP 状态码 200]
- [ ] [如：响应体包含 access_token 字段]
- [ ] [如：响应体包含 refresh_token 字段]
- [ ] [如：Cookie 中设置了 session_id]
- [ ] [如：页面跳转到 /home]

### 6.2 异常流程期望
- [ ] [如：错误邮箱 → HTTP 401, "邮箱或密码错误"]
- [ ] [如：错误密码 → HTTP 401, 密码输入框清空]
- [ ] [如：空输入 → HTTP 400, "请输入邮箱" / "请输入密码"]
- [ ] [如：5次连续失败 → HTTP 423, "账号已锁定"]

### 6.3 边界条件期望
- [ ] [如：密码长度=8 → 允许提交]
- [ ] [如：密码长度=7 → 提示"密码至少8位"]
- [ ] [如：邮箱超长(255+字符) → HTTP 400]

## 10. 填写示例

> 以"用户使用正确邮箱和密码登录"为例：

| 字段 | 示例值 |
|------|--------|
| 用例编号 | TC-AUTH-001 |
| 用例名称 | 用户使用正确邮箱和密码登录成功 |
| 优先级 | P0 |
| 前置条件 | 数据库中存在用户 test@example.com，密码为 Hashed_CorrectPass123! |
| Step-1 | 打开 /login 页面 → 页面正常加载 |
| Step-2 | 输入邮箱 test@example.com → 显示输入内容 |
| Step-3 | 输入密码 CorrectPass123! → 显示为圆点 |
| Step-4 | 点击"登录"按钮 → 加载动画出现 |
| Step-5 | 验证结果 → 页面跳转至 /home，顶部显示"欢迎回来，测试用户" |
| 期望-正常 | HTTP 200, 响应含 access_token, 页面跳转 /home |
| 期望-异常 | 错误邮箱 → HTTP 401, "邮箱或密码错误" |
| 清理 | 删除测试用户 session, 清除浏览器 localStorage |
