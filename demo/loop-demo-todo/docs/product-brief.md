# loop-demo-todo — 产品简报

## 项目目标

一个命令行 todo 管理工具，支持添加、查看、完成和删除待办事项。

## 用户画像

- **persona-001**: 开发者，习惯在终端工作，需要轻量级任务管理

## 用户故事

| ID | 角色 | 行为 | 目的 | 优先级 |
|----|------|------|------|--------|
| US-001 | 开发者 | 添加待办事项 | 记录需要完成的任务 | P0 |
| US-002 | 开发者 | 列出所有待办事项 | 查看当前任务列表 | P0 |
| US-003 | 开发者 | 标记事项为完成 | 跟踪进度 | P0 |
| US-004 | 开发者 | 删除事项 | 移除不再需要的任务 | P1 |

## 验收标准

### US-001: 添加待办
- Given 用户在终端，When 输入 `todo add "购买牛奶"`，Then 系统显示 "已添加: 购买牛奶"
- Given 已存在同内容事项，When 再次添加，Then 系统提示"事项已存在"

### US-002: 列出待办
- Given 有 3 条待办事项，When 输入 `todo list`，Then 显示编号+内容+状态列表
- Given 无待办事项，When 输入 `todo list`，Then 显示"暂无待办事项"

### US-003: 标记完成
- Given 事项 #1 未完成，When 输入 `todo done 1`，Then 显示"已完成: <内容>"
- Given 事项 #1 已完成，When 再次输入 `todo done 1`，Then 提示"事项已完成"
- Given 事项 #99 不存在，When 输入 `todo done 99`，Then 提示"事项不存在"

### US-004: 删除事项
- Given 事项 #1 存在，When 输入 `todo remove 1`，Then 显示"已删除: <内容>"
- Given 事项 #99 不存在，When 输入 `todo remove 99`，Then 提示"事项不存在"

## 范围边界

- **MVP**: US-001 + US-002 + US-003（添加/列出/完成）
- **Post-MVP**: US-004（删除）
- **不做**: GUI 界面、多用户、云同步、优先级标签、截止日期

## 非功能性需求

- 数据持久化：本地 JSON 文件存储
- 响应时间：<100ms
- CLI 接口：符合 GNU 风格参数规范
