# T-0136 D-01: 容量规划与压测方案设计（P0）

> 交付物：T-0136 批 2（AC-02）
> 覆盖能力域：容量规划与压测（面试题 #5 #6）
> 现状：❌ 全空白 —— NFR 模板仅「k6 压测」字样，无容量预估/资源计算/
> 压测方案/合格标准/容量上限推导
> 性质：candidate-only 设计

## 1. 设计目标

让 Loop 工程在为任意项目交付时，能够回答面试题全链问题：
「QPS 估算→资源投入→压测设计→合格标准→容量上限」，并落为可复用资产。

## 2. 三要素设计

### 2.1 模板（templates/ 新增）

**新增模板 A：`templates/capacity/capacity-estimate.md`（容量预估）**
- 输入：核心接口清单 + 业务量（DAU/UV/转化率）+ 峰值系数
- 计算步骤：
  1. 日常 QPS = 日请求量 / 86400 × 峰值系数（运营活动取 100× 起，见面试题
     2000→20 万场景）
  2. 读/写比例拆分（决定缓存/异步/分库分表方向）
  3. 资源粗算：单机吞吐基线（如 500~2000 QPS/核 依复杂度）+ 冗余系数
     （N+1 或 N+2）
  4. 产出：资源清单（实例数/内存/连接数/带宽）+ 假设清单（可复核）
- 内置 3 个示例场景：日常 2000 QPS / 活动峰值 20 万 QPS / 尖峰毛刺

**新增模板 B：`templates/capacity/load-test-plan.md`（压测方案）**
- 压测类型选择：单接口压测 / 链路压测 / 全链路压测
- 流量模型：真实流量回放（生产采样）+ 构造流量（正态/锯齿/尖峰三形态）
- 数据构造：影子库 + 标记流量（防污染生产，见 §3 门禁检查点）
- 压测工具矩阵：k6（脚本化）/ wrk（单接口）/ 生产回放（影子流量）
- 合格标准模板：
  | 指标 | 合格线 | 说明 |
  |---|---|---|
  | 目标 QPS 达成 | 100% | 持续 10 分钟无降级 |
  | p99 RT | ≤ 3× 基线 | 与日常 p99 对比 |
  | 错误率 | < 0.1% | 排除超时注入 |
  | 资源水位 | CPU ≤ 70% / 内存无 OOM | 留 30% 余量 |
  | 容量上限 | 找到拐点 | 继续加压至 RT 陡增处 |

### 2.2 角色知识（agents/ references 新增）

**归属角色：system-architect（容量设计）+ release-engineer（压测验收）**

`agents/system-architect/references/capacity-checklist.md`：
- 架构师在 S1/S2 阶段对 NFR 必须给出容量预估文档（含假设清单）
- 选型时必须回答「流量翻一倍/十倍是否成立」（面试题 #5 追问）
- 产出物：capacity-estimate.md + 资源清单

`agents/release-engineer/references/load-test-checklist.md`：
- 发布前检查：压测报告存在 + 合格标准逐项 PASS + 无污染证据
- 有活动峰值场景（≥10× 日常）必须做峰值压测，否则 NOGO

### 2.3 门禁检查点（发布检查新增项）

`release-checklist` / `delivery-manager` 门禁新增（report 级 → 后续可升级
BLOCKED 级）：
1. [CHECK] NFR 含容量预估文档（假设清单可复核）
2. [CHECK] 压测报告存在且覆盖目标 QPS（含峰值场景）
3. [CHECK] 压测流量防污染证据（影子库/标记流量说明）
4. [CHECK] 容量上限拐点已测（撑不到 2× 目标 QPS 需说明）

## 3. 与面试题的映射

| 面试题 | 方案回应 |
|---|---|
| 估算→落地怎么设计 | 模板 A 五步估算 + 资源清单 |
| 资源投入怎么算 | 单机吞吐基线 × 冗余系数 + 假设清单 |
| 怎么压测 | 模板 B：类型选择 + 流量模型 + 工具矩阵 |
| 压到何种程度算合格 | 四指标合格线 + 拐点判定 |
| 全链路压测/流量构造 | 影子库 + 标记流量 + 真实回放三形态 |
| 防污染生产 | 标记流量 + 影子库隔离（检查点 3） |
| 容量上限怎么得出 | 加压至拐点（检查点 4） |

## 5. 风险

| 风险 | 缓解 |
|---|---|
| 模板过于理论不可填 | 内置 3 个示例场景（含面试题 2000→20 万） |
| 压测合格线一刀切 | 合格线可配置（模板默认值 + 项目调整） |
| 检查点误伤轻量项目 | 检查点按项目规模分级（report → BLOCKED 由项目配置） |
