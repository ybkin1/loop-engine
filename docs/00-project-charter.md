# 00 — 项目章程

## 项目名称
Loop Engine（Loop 工程软件交付系统）

## 定位
ZCode 插件。把 AI 编码从"生成 demo"变成"具备产品经理、架构师、开发工程师、质量工程师、安全工程师、交付经理完整职责的可交付软件工程系统"。

## 目标用户
无代码能力、无项目管理背景的个人用户。用户的职责是描述目标、确认业务规则、做关键取舍、批准阶段 Gate。AI 工程团队负责剩下的一切。

## 核心能力
1. **11 个专业角色**：产品经理 / 项目经理 / 系统架构师 / 模块架构师 / 开发工程师 / 质量工程师 / 安全工程师 / 独立代码评审员 / 交付经理 / 发布工程师 / 主控会话
2. **确定性质量门**：lint / typecheck / test / coverage / audit / build 六项强制检查，机器裁决，不依赖 AI 自评
3. **证据链绑定**：从需求到交付的完整 hash 链，任一环节输入变更 → 下游证据自动 stale
4. **阶段 Gate**：12 个软件工程阶段，每个阶段产出 Human Review Packet，由人决定放行
5. **角色能力认证**：每个角色必须通过隔离的挑战测试才能接受生产任务

## 非目标
- 不是通用 CI/CD 工具
- 不是项目管理 SaaS
- 不是代码生成器
- 不会替代人类做业务目标决策

## 当前阶段
S0-init。第一个任务：完成项目章程、需求规格和架构设计文档。
